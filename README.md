# NITRO RACING MODZ

> High-Performance Superbike Diagnostics, Routine Maintenance & Custom Fabrication Studio.

State-of-the-art superbike service workshops across Ambattur and Avadi in Chennai. Built with Angular 19, Tailwind CSS v4, and modern GPU compositor-driven animations.

## Live Website
* **Live Demo (GitHub Pages):** [https://arivomtechnologies.github.io/NITRO-RACING/](https://arivomtechnologies.github.io/NITRO-RACING/)

## Key Features
* **Automotive Luxury Design:** Dark aesthetic (`#0A0C10`, `#11151F`, `#00E676` Nitro Green, `#38BDF8` Ice Cyan).
* **Interactive Service Cost & Bay Time Estimator:** Real-time labor and fluid specification calculations based on displacement CC classes.
* **Full Widescreen Showroom & Hubs:** Multi-bay workshop presentation with live telemetry HUD brackets and 1-tap mobile booking.
* **Build Gallery & Lightbox:** 12 documented superbike projects and titanium exhaust fabrication archive.
* **Verified Reviews & Telemetry:** 4.9-star rating showcase with 1,200+ closed digital job cards.
* **Universal Motion Engine:** Native CSS `view()` animation timelines with `IntersectionObserver` & `MutationObserver` fallback for 100% cross-browser compatibility.

## Tech Stack
* **Framework:** Angular 19 (Standalone Components)
* **Styling:** Tailwind CSS v4 & PostCSS
* **Routing:** Angular Declarative SPA Router with GitHub Pages `404.html` redirection
* **Deployment:** GitHub Pages & GitHub Actions CI/CD
